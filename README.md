### <a href="https://github.com/Anu1606-dev/CodeAtlas">CodeAtlas</a>

An AI-powered codebase explorer that connects GitHub repositories, indexes code with embeddings, and lets developers ask natural-language questions with grounded answers and real file/line citations.

What makes it fun: structure-aware chunking, Gemini embeddings, MongoDB Atlas Vector Search, GitHub OAuth, a BullMQ/Redis re-indexing queue, and a 3D dependency graph — all built around one rule: answers should trace back to retrievable code.

`React` `TypeScript` `Node.js` `Express` `MongoDB Atlas` `Gemini` `Redis` `BullMQ` `GitHub OAuth`
